# 📊 Analisador de Gastos e Gerador de Relatório Financeiro

Script em Python que automatiza a leitura de dados financeiros via CSV, realiza agrupamento de despesas com Pandas, gera gráficos de pizza com Matplotlib e exporta um relatório executivo em PDF usando ReportLab.

## 🛠️ Tecnologias
- Python 3
- Pandas
- Matplotlib
- ReportLab

## 🚀 Como Rodar
```bash
pip install -r requirements.txt
python relatorio.py
